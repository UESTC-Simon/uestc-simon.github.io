## Begin with a question

What would you like to understand? A short opening can establish the problem without promising an answer too early.

> A useful research note can preserve a question as carefully as it preserves a result.

## Record the evidence

1. Describe the setting.
2. Separate observations from interpretations.
3. Link to the sources that support the argument.

Inline code such as `model.eval()` is supported, along with [ordinary links](https://arxiv.org/).

```python
def record_observation(question, evidence):
    return {"question": question, "evidence": evidence}
```

## Keep the limits visible

| Observation | Interpretation |
| --- | --- |
| A documented result | A hypothesis to investigate |
| An unresolved case | A useful next question |
