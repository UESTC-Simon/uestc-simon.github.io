## 从一个问题开始

这篇笔记想弄清什么？先说明问题的背景，再逐步展开证据和推理。

> 研究笔记既可以保存结论，也可以认真保存一个尚未解决的问题。

## 记录证据

1. 描述实验或观察的设置。
2. 区分已经发生的事实与自己的解释。
3. 在相关段落中附上来源。

支持行内代码 `model.eval()`，也支持[普通链接](https://arxiv.org/)。

```python
def record_observation(question, evidence):
    return {"question": question, "evidence": evidence}
```

## 保留不确定性

| 观察 | 解释 |
| --- | --- |
| 已记录的实验结果 | 需要检验的假设 |
| 尚未解决的情况 | 值得继续追问的问题 |
